# ModpSelmerGroups
Magma code to compute relaxed, nearly-ordinary and unramified Selmer groups associated to mod p Galois representations.

This is associated to the paper "Computing Selmer groups associated to mod $\boldsymbol{p}$ Galois representations".

For the version of this code used for computations in my thesis, "Periods and Selmer groups associated to mod p Galois representations over imaginary quadratic fields", see [the other branch](https://github.com/lewismcombes/ModpSelmerGroups/tree/thesis) of this repository.
